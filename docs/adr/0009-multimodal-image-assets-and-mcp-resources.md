# 0009: 多模态图片资产管理与双轨多端共享规范（MCP Resources + S3）

## 背景与问题
知识库文档常包含本地图片（`![alt](./assets/pic.png)`）与远程网络外链。在个人单机环境下，本地路径仅本机可读；但在团队协作或跨主机 MCP 访问场景下，本地路径在其他成员或远端客户端会直接失效（404），且外链图片存在防盗链与失效风险。

## 架构决策
决定建立结构感知与双轨共享的多模态图片资产处理管道：
1. **切片语法原子保护**：Markdown 与 HTML 切片器保护图片语法块不被意外截断；
2. **图文语义注入**：提取图片的 `alt` 替代文本与紧邻上下文段落一同参与 Embedding 计算，确保图片相关问题能精准召回；
3. **团队访问双轨制**：
   - **原生 MCP Resource 轨道**：利用标准 MCP 协议 `resources` 规范（`rag://assets/{kb_name}/{doc_id}/{filename}`）透出图片资产，无需开放 HTTP 端口即可让团队客户端与 Agent 直接拉取图片内容；
   - **企业对象存储轨道**：支持配置 S3 / MinIO / 阿里云 OSS（`MCP_RAG_STORAGE_TYPE=s3`），摄取本地图片自动同步上传并转为团队公网/内网可访问的 HTTPS 永久链接；
4. **外链图片安全策略**：默认仅透出原始 URL 避免 SSRF 风险；提供可选开关 `MCP_RAG_ARCHIVE_REMOTE_IMAGES=false` 支持在必要时异步转存归档防失效。
