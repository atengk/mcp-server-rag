# 0012: 切片双向链表与邻近上下文动态展开窗口规范

## 背景与问题
固定窗口切片在处理跨段落逻辑、长代码块或表格时容易产生截断，导致大模型在阅读单一切片时丢失前后关键背景信息。若单纯增大切片或重叠窗口，又会导致存储膨胀与检索冗余。

## 架构决策
决定引入轻量双向链表与按需动态展开窗口机制：
1. **轻量双向关联元数据**：切片生成与入库时，在元数据中隐式记录 `chunk_index`、`prev_chunk_id` 与 `next_chunk_id`，不增加正文冗余；
2. **按需邻近展开（Neighboring Context Window）**：
   - 在 `rag_search` 检索接口中增加可选参数 `expand_context: int = 0`；
   - 默认值为 0，保持精炼切片输出；
   - 当调用方指定 `expand_context=N` 时，系统在最终结果组装阶段自动查询并按物理顺序缝合命中切片的前后 N 个相邻切片，为需要复杂推理与完整视角的 Agent 提供连贯全景上下文。
